概述

antiSMASH（antibiotics & Secondary Metabolites Analysis Shell）是一个广泛使用的生物信息学工具，用于在基因组序列中识别次级代谢产物生物合成基因簇（BGCs）。antiSMASH 支持细菌、真菌和植物基因组分析，提供详细的基因簇类型、功能注释和比较分析结果。

本项目实现了一个 Model Context Protocol (MCP) 服务器，使 AI 助手（如 Claude）能够直接与 antiSMASH 数据库交互，实现次级代谢产物生物合成基因簇的自动化分析。

支持的 antiSMASH 服务器

服务器类型 描述 URL
bacteria 细菌版本（默认） antismash.secondarymetabolites.org
fungi 真菌版本 fungismash.secondarymetabolites.org
plant 植物版本 plantismash.secondarymetabolites.org

检测严格度

严格度 描述
strict 严格模式：检测包含所有必需部分的完整基因簇
relaxed 宽松模式（默认）：检测缺少一个或多个功能部分的部分基因簇
loose 松散模式：使用更宽松的标准，可能包含更多假阳性结果

安装

前置条件

  • Python 3.10 或更高版本
  • pip 包管理器

从源码安装

bash
# 克隆仓库
git clone https://github.com/ZengZichao/antiSMASH-MCP.git
cd antiSMASH-MCP

# 安装包（推荐使用虚拟环境）
pip install -e .

依赖项

以下依赖项会在安装时自动安装：

  • mcp>=1.0.0 — Model Context Protocol SDK
  • httpx>=0.25.0 — 异步 HTTP 客户端
  • pydantic>=2.0.0 — 数据验证

配置

环境变量

环境变量 默认值 描述
ANTISMASH_MCP_LOG_LEVEL INFO 日志级别（DEBUG/INFO/WARNING/ERROR）
ANTISMASH_MCP_SERVER bacteria 默认 antiSMASH 服务器类型

直接运行

bash
# 使用默认配置运行
python -m antismash_mcp.server

# 或者使用安装的命令行工具
antismash-mcp

Claude Desktop 配置

macOS/Linux: ~/.config/claude/claude_desktop_config.json   Windows: %APPDATA%\Claude\claude_desktop_config.json

json
{
  "mcpServers": {
    "antismash": {
      "command": "python",
      "args": ["-m", "antismash_mcp.server"],
      "env": {
        "ANTISMASH_MCP_LOG_LEVEL": "INFO"
      }
    }
  }
}

可用工具

本 MCP 服务器提供以下 10 个工具：

  • submit_sequence 提交序列文件到 antiSMASH 进行分析
  • submit_ncbi 使用 NCBI 登录号提交分析任务
  • check_job_status 检查任务状态（queued/running/done/error）
  • wait_for_job 等待任务完成（阻塞操作）
  • get_job_results 获取已完成任务的分析结果摘要
  • get_job_details 获取任务的详细信息
  • download_results 下载结果压缩包（ZIP 文件）到本地
  • get_server_status 获取 antiSMASH 服务器状态
  • list_extra_features 列出所有可用的额外功能及描述
  • get_example_url 获取 antiSMASH 示例输出页面 URL

使用示例

场景一：提交并分析基因组序列

对话示例
用户：帮我提交 NC_003888.3 到 antiSMASH 进行分析

AI：好的，我正在使用 submit_ncbi 工具提交 NCBI 登录号 NC_003888.3 到 antiSMASH...

    你可以在以下网址查看结果: https://antismash.secondarymetabolites.org/ABC12345

用户：检查一下任务状态

AI：[调用 check_job_status 工具]
    任务目前正在运行中...

场景二：获取分析结果

对话示例
用户：任务完成了吗？帮我看看结果

开发指南

开发环境搭建

bash
# 克隆仓库
git clone https://github.com/ZengZichao/antiSMASH-MCP.git
cd antiSMASH-MCP

# 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate  # Windows

# 安装开发依赖
pip install -e ".[dev]"
